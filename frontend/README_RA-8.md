# RA-8 — запись и сохранение WAV на Android

## 1. Что добавлено

| Папка / файл | Для чего нужен |
| --- | --- |
| `frontend/services/index.ts` | Экспорт функций, которые нужно вызывать из экранов. |
| `recordingService.ts` | Запуск/остановка записи, разрешение микрофона, обработка ошибок. |
| `storage.ts` | Создание папок учеников и сохранение WAV. |
| `naming.ts` | Безопасные имена папок и файлов, защита от перезаписи. |
| `types.ts` | Настройки, частоты записи и коды ошибок. |
| `frontend/modules/wav-recorder/` | Нативный Expo-модуль для Android (Kotlin): захват звука через `AudioRecord` и запись PCM в WAV. **Его нужно включить в сборку приложения.** |

**Не нужно** писать свою запись звука, создавать папки вручную или обращаться к нативному модулю из экрана: используй `services`.

## 2. Как подключить к Expo-приложению (RA-9)

1. Добавь обе папки — `services` и `modules/wav-recorder/` — в **корень Expo-приложения** (рядом с `package.json` должны быть папки `services/` и `modules/`). Не помещай их внутрь `app/` Expo Router. Если Expo-проект находится не в `frontend/`, перенеси **обе** папки вместе.
2. В терминале, находясь в папке Expo-приложения с `package.json`, выполни:

   ```bash
   npx expo install expo-file-system expo-modules-core expo-dev-client
   npx expo run:android --device
   ```

3. Собери приложение на **реальном Android-телефоне** с включённой USB-отладкой (понадобятся Android SDK и JDK). Expo сам подключает локальный модуль из `modules/`. Запрос разрешения на микрофон уже реализован. После изменений Kotlin-кода нужно заново собрать приложение.

**Важно:** RA-8 **не работает в Expo Go и на iOS**. Нужен Android development/production build. `expo-sqlite` относится к RA-7; отдельно для RA-8 устанавливать его не требуется.

## 3. Как использовать в экране записи (RA-10)

```ts
import {
  startRecording,
  stopRecording,
  RecordingError,
} from '../services'; // скорректируй путь под свой экран

// Обработчик кнопки Start. student — выбранный ученик из RA-7.
async function onStart(student: { id: number; firstName: string; lastName: string }) {
  try {
    await startRecording({
      student,
      textId: 'T01', // ID текста, который читает ученик
      sampleRate: 16000,
    });
    // Только теперь показать в UI, что запись идёт.
  } catch (error) {
    if (error instanceof RecordingError) console.error(error.code);
  }
}

// Обработчик кнопки Stop.
async function onStop() {
  try {
    const wavUri = await stopRecording();
    console.log('Готовый WAV:', wavUri);
    // Только теперь показать успешное сохранение.
    // URI можно передать для воспроизведения или в RA-14 (метаданные SQLite).
  } catch (error) {
    if (error instanceof RecordingError) console.error(error.code);
  }
}
```

`student` можно передавать прямо из `listStudents(classId)` (RA-7). Частота по умолчанию — **16000 Hz**; доступны `16000`, `22050`, `32000`, `44100` Hz (для RA-16). Формат всегда **WAV без сжатия, 16-bit PCM, mono**. `textId` — короткий код, например `T01` (латинские буквы, цифры, `_` или `-`; максимум 64 символа; начинается с буквы или цифры).

## 4. Куда сохраняются записи

Пример внутреннего хранилища приложения:

```text
deti/
  Jan_Novak_12/
    2026-10-18_T01.wav
    2026-10-18_T01_2.wav
```

Папка создаётся автоматически по имени, фамилии и **ID ученика**. Дата берётся с телефона при начале записи. Повторная запись того же текста не перезапишет предыдущую. Готовые файлы сохраняются после перезапуска приложения; удаляются при удалении приложения или очистке его данных. `stopRecording()` возвращает локальный `file://` URI, а не ссылку для скачивания.

## 5. Что важно учесть в интерфейсе

- Разрешение на микрофон запрашивается при Start. Если пользователь отказал (`MICROPHONE_PERMISSION_DENIED`), не показывай состояние «идёт запись».
- Одновременно возможна только одна запись. Повторный Start выдаст `RECORDING_BUSY`.
- Выход с экрана или перевод приложения в фон: вызови `stopRecording()` и обработай результат; фоновая запись **не поддерживается**.
- Если Stop вернул `SAVE_FAILED`, временный WAV сохранён: после устранения причины **повтори `stopRecording()`**, не запускай новую запись. Ошибки доступны через `RecordingError.code`.

**Статус:** сервис и WAV-формат проверены вне приложения, но полный Android build и работа микрофона в Expo-приложении RA-9 **ещё не проверены**. При интеграции нужно сделать реальную запись на телефоне и проверить воспроизведение и сохранение файла. Подробнее: `docs/RA-8-local-recordings.md`.
