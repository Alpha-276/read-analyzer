## 🎯 Цели и ценность проекта

* **Проблема:** Учителям начальных и средних классов сложно вручную выявлять скрытые нарушения дикции, заикания, бедный словарный запас и темпо-ритмические отклонения у десятков учеников.
* **Решение:** Автоматизированный сервис, принимающий аудиозаписи чтения и ответов детей, распознающий речь (ASR) и выявляющий характерные речевые проблемы:
  * Нетипично длинные паузы и прерывистость речи.
  * Повторы слогов и слов (признаки заикания).
  * Скорость речи (Words Per Minute — WPM).
  * Лексическое разнообразие и словарный запас.
  * Динамика прогресса ребенка на протяжении учебных четвертей и лет.
* **Датасет:** Исторические данные 500 детей, записывавшихся на протяжении 2 лет, используемые для калибровки и экспериментов на суперкомпьютере.

## 🏗️ Архитектура монорепозитория

Проект построен как монорепозиторий (Monorepo), разделенный на независимые модули:

```text
read-analyzer/
├── backend/            # Серверная часть (FastAPI, PostgreSQL, асинхронный воркер)
│   ├── app/            # Исходный код API и бизнес-логики
│   └── tests/          # Юнит-тесты и интеграционные тесты
│
├── frontend/           # Веб-интерфейс для учителей (React / Vite / Tailwind)
│   └── src/            # Компоненты, дашборды, аудиоплеер
│
├── ml/                 # Исследования и алгоритмы обработки аудио
│   ├── pipeline/       # Инференс Whisper, шумоподавление, извлечение пауз
│   ├── scripts/        # SLURM-скрипты для суперкомпьютера
│   └── samples/        # Тестовые аудиофайлы для юнит-тестов
│
├── .github/workflows/  # CI пайплайны (проверка кода, автотесты)
├── docker-compose.yml  # Оркестрация локального окружения
└── README.md           # Документация проекта
```

## 🚀 Быстрый старт

### Требования
* **Python** 3.11+
* **Node.js** 20+
* **Docker & Docker Compose** (опционально для локального развертывания БД)

### 1. Клонирование репозитория
```bash
git clone https://github.com/Alpha-276/read-analyzer.git
cd read-analyzer
```

### 2. Запуск Backend
```bash
cd backend
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
# source .venv/bin/activate

pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```
API документация доступна по адресу: `http://localhost:8000/docs`

### 3. Запуск Frontend
```bash
cd frontend
npm install
npm run dev
```

## 📋 Правила работы с Git (Git-Flow)

1. **Ветка `main` стабильна:** Прямые коммиты в `main` запрещены. Все изменения вливаются через Pull Request (PR) с минимум 1 ревью.
2. **Именование веток строго по Jira тикетам:**
   * `feature/RA-5-dataset-validation`
   * `feature/RA-7-backend-init`
   * `feature/RA-9-frontend-init`
   * `bugfix/RA-XX-fix-audio-upload`
3. **Хранение данных:**  
   Большие файлы датасета (`*.wav`, `*.mp3`) и веса нейросетей (`*.pt`, `*.bin`) **запрещено** пушить в Git. Используйте тестовые 5-секундные сэмплы в директории `ml/samples/`.

## 📈 План спринтов (Roadmap)

* **Спринт 1:** Каркас архитектуры, API загрузки аудио, базовая верстка, аудит датасета 500 детей.
* **Спринт 2:** Сквозной пайплайн распознавания речи (Whisper), расчет скорости речи и пауз, плеер с таймлайном.
* **Спринт 3:** Алгоритм детекции заиканий/аномалий, скрипты для суперкомпьютера, профили учеников и экспорт в PDF.
* **Спринт 4:** Комплексный дашборд динамики развития ребенка, стресс-тестирование, оптимизация инференса.
* **Спринт 5:** Багфикс, нагрузочное тестирование, оформление документации и подготовка к защите проекта.
